# VELORA

A pinned product scroll for The Still. Portfolio preview only. Nothing is saved on a server.

## Publish on Vercel

Import this repo. Framework: TanStack Start. Build command: `npm run build`.

Do not add a database, `DATABASE_URL`, or Postgres. The bag stays in the browser. Sign-in is off.

## Skill

[John-WebsiteScrollAnima-Ver1](John-WebsiteScrollAnima-Ver1/SKILL.md) is the scroll style used for this site. The agent copy lives at `.grok/skills/john-websitescrollanima-ver1` (same files). GitHub hides folders that start with a dot, which is why the skill looks missing until you open that path.
